CS1.6 Custom Models Repository

This repository contains custom player and zombie models for Counter-Strike 1.6.

Installation

  1. Copy the models folder into your cstrike directory.
  2. Restart your server or game to see the changes.

Notes

  • Compatible with Zombie Plague 4.3 or custom CS1.6 servers.
  • Configure server.cfg or zp_zombieclasses.ini to use custom models.
